# 배출량 개선 계획

> **문서 순서:** 앞선 [02 기존 체계 분석](02_Legacy_SMOKE27_Emission_Processing.md)을 근거로 개선 원칙을 정리한 문서입니다. 실제 입력 생성·검증은 [04 실행 가이드](04_SMOKE_Busan_Case_Run_Guide.md)를 따르세요.

> **목표:** 최신 프로그램(WRF 4.5.1 · SMOKE 5.3 · CMAQ 5.5)으로 부산 대기질 모델링 시스템을 교체하면서, 배출량(국내·국외)을 기존 체계에 쓰인 자료(CAPSS 2017 등)보다 최근 자료로 교체하고, 종분배·공간·시간 프로파일 등 개선할 수 있는 입력은 최신 자료로 개선한 새 배출량 체계를 만든다.
> **작성:** 2026-10-22. 이 문서는 **계획과 결정 사항**을 정리한다. 실제 SMOKE 실행 기록은 [CAPSS 2023 기준 부산 사례 실행 가이드](04_SMOKE_Busan_Case_Run_Guide.md)에 국내 점 A단계부터 남긴다.
> **검증 근거:** 사용자 제공 자료(CAPSS 2017·2023 1km 격자 배출량과 코드리스트·파일설명, 기존 운영체계 SMOKE 2.7 입력 파일, L-NEAS SMOKE 구동 매뉴얼 v1.0.1)를 작성 환경에서 직접 열어 확인했다. 2026-10-22 계획 작성 당시에는 새 체계 배출량을 아직 SMOKE로 실행하지 않았다. **2026-10-30 갱신:** 국내 CAPSS 2023 점·면·이동·바다 4개 부문 × 27·09·03·01KM 완료(사용자 제공 2026-10-23~29 Linux 실행 기록 기준). 점 인벤토리 보고서 합계와 면·이동·바다 NOx 격자 합계 일치. 다음은 국외(HTAP v3.1)·생물성·병합 및 CMAQ 연계 검증. 이번 GitHub 등록 과정에서 그 원자료나 모델을 별도 재검증·재실행하지 않았다.

관련 문서: [기존 운영체계 배출량 산정 구조 분석](02_Legacy_SMOKE27_Emission_Processing.md) · [SMOKE 5.3 설치 및 공식 예제 검증](01_SMOKE_Installation_Guide.md) · [부산 사례 실행 가이드](04_SMOKE_Busan_Case_Run_Guide.md)

## 4. 확인된 사실과 결정 사항

### 4.1 CAPSS 1km 격자 원자료 형식

| 항목 | 내용 |
|---|---|
| 파일 | 점오염원 `지역+p.txt`, 면 `지역+a.txt`, 이동 `지역+m.txt`, 점오염원 식별(사업장명·TMS) 별도. 쉼표 구분, 머리줄 있음 |
| 점오염원 열 | `INVEST_YEAR, ADMIN_CD, POINT_ID, SCC_CD, FUEL_CD, TM_X, TM_Y, ALTITUDE, STACK_HEIGHT(m), STACK_DIAMETER(m), GAS_TEMPER(℃), GAS_SPEED(m/s), CO, NOx, SOx, TSP, PM-10, VOC, NH3, PM-2.5` |
| 면·이동 열 | `INVEST_YEAR, ADMIN_CD, TM_X, TM_Y, ALTITUDE, SCC_CD, FUEL_CD,` 오염물질 8종 |
| 단위 | **kg/yr** (metric) |
| 좌표 | TM km. Bessel 1841, Tokyo 측지계, 중부원점(경도 127°00′10.405″, 위도 38°), False Easting 200,000 m, False Northing 500,000 m. 면 자료는 격자 왼쪽 아래 기준. 2019년 자료부터 경위도판(격자 중심)도 제공 |
| 코드 | 시군구 10자리(2023) / 5자리(2017), SCC 8자리, 연료 5자리 |
| 바다 | 2014년 자료부터 포함. 2023 지역 코드 `9010000000`(바다), 선박 SCC `0803…` |

2023 원자료는 기존 체계의 해상 전용 SCC(`98…`)를 쓰지 않고 **바다 지역 코드로 구분**한다.

TM → 위경도 변환식(pyproj):

```text
+proj=tmerc +lat_0=38 +lon_0=127.002890277778 +k=1 +x_0=200000 +y_0=500000 +ellps=bessel
+towgs84=-115.80,474.99,674.11,1.16,-2.31,-1.63,6.43 +units=m +no_defs
```

확인: 2023 점오염원 첫 레코드(서울 종로구, TM 197.103, 451.813 km) → 126.968°E, 37.569°N.

### 4.2 단위: kg/yr → short ton/yr

SMOKE는 인벤토리의 ton을 short ton(907.18474 kg)으로 처리한다. 2017 원자료(kg/yr)와 기존 IDA 점오염원 값을 비교하면 비율 중앙값이 **907.19**로, 기존 IDA는 `kg ÷ 907.18` short ton으로 정확히 변환되어 있었다. 새 체계도 **kg ÷ 907.18474**로 변환한다(L-NEAS 매뉴얼 p.14의 short ton 변환과 같음).

### 4.3 SCC 10자리 체계와 기존 연료 번호

기존 체계와 L-NEAS는 SCC 8자리 뒤에 연료(이동오염원은 도로+연료) 2자리를 붙인 10자리를 쓴다. 시간·종분배 참조가 10자리 SCC 기준이므로 2023 원자료(연료 5자리)를 같은 10자리로 바꿔야 기존 참조를 이어 쓸 수 있다.

기존 체계의 2자리 연료 번호는 CAPSS 코드리스트에 없는 **기존 체계 고유 번호**다(2017 원자료도 연료 5자리). 2017 원자료 점오염원과 기존 IDA 점오염원을 배출량 값으로 짝지어(2,142쌍) 규칙을 찾았다.

> **2자리 번호 = 2017 연료 코드표에서 대분류 줄(코드 끝 `00`)을 뺀 순번.** 예외: `20500`(등유) → `44`, `999xx`(기타 전부) → `99`.

| 2자리 | 연료 | 2자리 | 연료 |
|---|---|---|---|
| 02 | 비민수용무연탄 10102 | 36·37·39 | 경유 1.0%·0.4%·0.1% |
| 07 | 유연탄 10201 | 44 | 등유 20500 |
| 19·20 | B-A유 0.5%·0.3% | 45 | 보일러등유 20502 |
| 28~33 | B-C유 4.0%~0.3% | 80 | 프로판 40101 |
| 82 | LNG 40201 | 99 | 기타 999xx |

짝지어진 모든 연료에서 규칙과 어긋나는 경우가 없었다. L-NEAS 매뉴얼 붙임 1의 연료 2자리(예: 유연탄 `81`, LNG `41`)는 **다른 체계**이므로 섞어 쓰지 않는다.

**2017 코드표에 없는 2023 연료 8종**은 새 코드를 붙이고, 참조는 성질이 가까운 연료에서 빌린다.

| 연료 | 새 코드 | 참조를 빌릴 연료 |
|---|---|---|
| 정유가스 23101 | G1 | LNG 82 |
| 고로가스 50101 / 전로가스 50102 / 코크스가스 50103 | G2 / G3 / G4 | LNG 82 |
| 소화가스 50201 / 매립가스 50202 | G5 / G6 | LNG 82 |
| SRF 80201 / BIO-SRF 80202 | S1 / S2 | 유연탄 07 |

영문이 들어간 SCC를 SMOKE 5.3이 읽는지는 첫 실행에서 확인한다. 문제가 있으면 쓰이지 않는 숫자 번호로 바꾼다.

### 4.4 시간·종분배 참조 보완 규칙

| 순서 | 규칙 |
|---|---|
| 1 | 기존 10자리 SCC 참조와 정확히 일치 |
| 2 | 새 연료는 빌린 연료 번호로 일치 |
| 3 | 같은 SCC 8자리의 다른 연료 참조 (LNG 82 → 기타 99 → 프로판 80 → B-C유 33 순으로 우선) |
| 4 | 같은 상위 분류(SCC 앞 6자리) 참조 |
| 5 | SMOKE 기본 프로파일 |

빌린 참조는 모두 출처를 기록한다(`scc10_reference_map`). 2023 점오염원 적용 결과: 조합 269개 중 정확 일치 178, 빌린 연료 25, 같은 SCC 55, 기본값 11. 배출량 기준 NOx 99.8%, VOC 99.99%가 기존 참조 또는 빌린 참조를 받는다.

### 4.5 점오염원 굴뚝 제원 보완 규칙

결측(빈칸)과 0 이하 값을 결측으로 보고 차례로 채운다. 채운 내역은 기록 파일로 남긴다.

| 순서 | 규칙 |
|---|---|
| 0 | 같은 굴뚝(`POINT_ID`)의 다른 줄 값 |
| 1 | 같은 SCC·연료 굴뚝들의 중앙값 |
| 2 | 같은 SCC 중앙값 |
| 3 | 전체 중앙값 |

2023 점오염원(14,437줄): 온도 결측 1,660, 속도 결측 1,841, 높이 0 이하 220, 내경 0 이하 225. 거의 모두 1번 규칙으로 채워진다. 같은 지역·굴뚝·SCC·연료의 중복 148줄은 합친다.

| VOC→TOG | 예제 `gscnv_SPECIATE_5_3`의 **프로파일별 계수** 사용. 기존 SCC별 계수 대비 국내 면 TOG 총량 97.7% |
| 기타 물질 | CO·NH3·SO2 `0000`, PMC `99999`(예제 정적 프로파일), NOX `HONO`(NO 0.9 / NO2 0.092 / HONO 0.008, 기존과 같은 비율) |
| 확인할 것 | CMAQ 5.5 기본 메커니즘(cb6r5 계열)과 CB6R3_AE7 배출 물질 이름 대응 — 병합 단계 |

### 4.8 공간배분 (계획)

CAPSS 2023 1km 격자 배출량에서 **시군구 안의 SCC별(필요 시 SCC10별) 격자 분포**를 뽑아 4개 도메인 격자로 옮겨 대리자료를 만든다. 기존 체계 대리자료도 같은 원리(CAPSS 격자 분포, 시군구별 합계 1)였으므로 방법은 유지하고 자료만 2023으로 바꾼다.

- 바다(`90100`)도 같은 방법으로 4개 도메인 모두 만든다 → 기존 3·1km 해상 대리자료 부재 문제 해결
- 시군구 경계를 넘는 몫(영역 밖)은 기존처럼 버려진다
- 대리자료 형식: SMOKE 표준(`#GRID` 머리말 + `번호 지역 열 행 비율`). 기존 조각 파일 규칙은 따르지 않아도 됨

### 4.9 국외 배출량: HTAP_v3.1

| 항목 | 내용 |
|---|---|
| 자료 | HTAP_v3.1 emission mosaic (TF-HTAP, JRC). 0.1°, 월별, 2000~2020년, SO2·NOx·CO·NMVOC·NH3·PM10·PM2.5·BC·OC. 북미·유럽·아시아(중국 MEIC, 일본·한국 공식 인벤토리)와 나머지 EDGARv8 통합. NMVOC 종분배 프로파일 제공 |
| 사용 연도 | 2020년 (자료 최신 연도) |

| 필수 처리 | **남한 격자 제외**(국내는 CAPSS 2023만 사용, 이중 계상 방지). 북한은 HTAP에 포함되므로 별도 파일 불필요 |
| 적용 도메인 | 27·09km (기존과 같음) |
| 대안 | CAMS-GLOB-ANT v6.2 (0.1°, 2000~2026, 2023년 직접 사용 가능, 일부 지역 NOx·SO2 문제 보고) |

### 4.10 시간배분

기존 프로파일(월 833, 요일 48, 시간 87개)과 SCC별 참조를 유지한다. 기존 평일·주말 일변화가 모두 같아 SMOKE 5.3 형식에서는 `ALLDAY` 하나로 쓴다. L-NEAS(`N19.v6.amptpro`) 등 최신 국내 프로파일을 확보하면 교체를 검토한다.

## 5. 진행 방식

자료를 미리 다 만들어 두지 않고, **SMOKE를 부문별·단계별로 실제로 돌리면서 그 단계의 입력만 점검하고 보완한다.**

### 5.1 단계마다 하는 일

| 순서 | 내용 |
|---|---|
| ① 설명 | 이 단계에서 도는 프로그램과 하는 일 |
| ② 입력 점검표 | 이 단계가 읽는 파일만: 기존 그대로 / 개선 / 신규와 이유 |
| ③ 보완 | 개선·신규 파일만 이 자리에서 생성 (생성기와 함께 저장소 보관) |
| ④ 실행·확인 | 로그와 결과 합계 확인 |
| ⑤ 기록 | 실행 가이드에 단계 추가, 이 문서 §2 상태 갱신 |

### 5.2 SMOKE 단계

| 단계 | 프로그램 | 점검할 입력 |
|---|---|---|
| A | Smkinven | FF10 인벤토리, INVTABLE, 코드표 |
| B | Spcmat | 종분배 참조·프로파일·변환계수 |
| C | Grdmat | GRIDDESC, 대리자료 설명·참조·대리자료 |
| D | Temporal | 시간 참조·프로파일, 공휴일, 날짜 |
| E | Smkmerge (점오염원은 굴뚝 처리 포함) | 기상(MCIP) |
| F | Smkreport | 보고서 설정 → 원자료 합계와 비교 |

### 5.3 부문 순서

| 순서 | 부문 | 핵심 개선 |
|---|---|---|
| 1 | 국내 점 | CAPSS 2023, 굴뚝 보완, SCC10 참조 연결 |
| 2 | 국내 면·이동·바다 | CAPSS 2023, 1km 격자 기반 대리자료(바다 포함) |
| 3 | 국외 | HTAP_v3.1, 남한 제외 |
| 4 | 생물성 | BEIS4 또는 MEGAN 3.x |
| 5 | 병합 | CMAQ 5.5 입력 |

각 부문은 09km로 먼저 통과시킨 뒤 27·03·01km로 넓힌다.

### 5.4 검증

L-NEAS 방식처럼 Smkreport 보고서(시도·시군구·SCC·시군구×SCC)를 원자료(kg → short ton 환산) 합계와 비교한다. 도메인 경계 밖 몫은 따로 계산해 차이를 설명한다.

## 6. 남은 확인·결정 사항

아래 표는 계획 작성 당시의 점검 목록이다. 국내 실행에서 확인한 결과·남은 한계는 04 §8~§10을 우선한다. 국내 완료가 공휴일 공식 검증이나 CMAQ 메커니즘 대응 검증 완료를 뜻하지 않는다.

| 항목 | 시점 |

| 영문 SCC(`G1`, `S1` 등)의 SMOKE 5.3 처리 여부 | 국내 점 A단계 |

| CAPSS 2023 면·이동·바다 파일의 SCC·연료 조합과 기존 참조 적용률 | 국내 면 A·B단계 |
