## 현재 작업 재개 위치

- **완료(2026-10-22 제공 작업 기록 기준):** SMOKE 5.3 공식 예제 검증, CAPSS 2023 국내 점·면·이동·바다 입력 일괄 생성·설치, Linux 09KM **국내 점 onetime 정상 완료(보고서 합계 일치)**.
- **다음:** 국내 점 09KM daily → 국내 면 → 이동 → 바다 → 4개 도메인 확장 → 국외(HTAP v3.1)·생물성·병합.
- **설치·생성 파일:** [files/busan/2023capss/](files/busan/2023capss/)에 설치 스크립트·생성기·실행 스크립트를 보관. 대용량 FF10·대리자료는 저장소에 없으며 설치 ZIP 또는 생성기로 만든다.
- **외부 참조파일:** 재현에는 CAPSS 코드리스트 2개 및 운영체계 참조 6개가 필요하다. 참조파일이 [reference/](files/busan/2023capss/reference/)에 등록되었는지 별도로 확인한다.
