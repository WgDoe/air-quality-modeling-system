## 현재 작업 재개 위치

- **완료(2026-10-23 제공 실행 기록 기준):** SMOKE 5.3 공식 예제, CAPSS 2023 국내 4부문 입력 생성·설치, 국내 **점·면 각 4개 도메인 처리 및 결과 검증**.
- **진행:** 국내 이동오염원(4개 도메인). 이후 바다 → 국외 HTAP v3.1·생물성 → 최종 병합.
- **재현성 주의(2026-10-24 저장소 확인):** 04 가이드의 선택 다운로드에 필요한 `file_list.txt`, MCIP 기간 연동 `mcip_period.py`, 패치한 `set_days_v5.csh`가 현재 `main`에 없다. 생성기와 부문별 실행 스크립트도 최신 수정본과 불일치한다. **04 가이드의 새로운 초기 구축 명령을 그대로 실행하지 않는다.**
- **참조자료:** [CAPSS 코드리스트 2개 및 운영체계 TXT 6개](files/busan/2023capss/reference/)는 GitHub에 존재한다. 대용량 FF10·surrogate 및 CAPSS 원자료는 저장소에서 내려받는 대상이 아니다.
