## 현재 작업 재개 위치

- **기록상 완료:** SMOKE 5.3 공식 예제 검증, CAPSS 2023 국내 점·면·이동·바다 FF10 및 4개 도메인 surrogate 생성(작성 환경), Linux 09KM 국내 점 **Smkinven 단독 형식 시험 정상 종료**.
- **후속 검증:** Linux 최종 설치 로그 확인, 국내 점 09KM `onetime` → `daily` → 국내 면 → 이동 → 바다; 이후 국외·생물성·병합 단계.
- **주의:** Smkinven 단독 시험 성공은 부문 전체 SMOKE 실행 완료를 의미하지 않는다. 실제 작업 명령은 [04 실행 가이드](04_SMOKE_Busan_Case_Run_Guide.md)를 따른다.
- **설치·생성 파일:** [files/busan/2023capss/](files/busan/2023capss/)에 일부 스크립트 및 생성기 보관. **대용량 FF10·surrogate는 저장소에 미등록**이므로 별도 ZIP 원본이 필요하다.
