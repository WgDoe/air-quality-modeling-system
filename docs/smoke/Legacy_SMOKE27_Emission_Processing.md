# 기존 부산 SMOKE 2.7 배출량 처리체계 분석 (참고자료)

> **문서 성격:** 기존 운영체계 역분석 참고자료. 신규 SMOKE 5.3 설치·실행 지침이 아님.  
> **분석 기준:** 2020년 버전 구성(국내 CAPSS 2017, 대리자료 2020 갱신 / 국외 2010 기준, 2016 갱신).  
> **검증 수준:** 2026-10-19 기준 기존 입력 파일·중간 산출물의 형식, 레코드 수, 합계 및 참조 관계를 대조한 기록. **기존 모델 재실행과 실행 로그 검증은 하지 않음.**  
> **원자료:** 사용자 제공 `Legacy_SMOKE27_Emission_Processing.md`. 자세한 필드 정의와 파일별 사항은 원자료 기준.  
> **범위:** `/home/busan_aqm/realtime_fnl_cmaq/smoke/smoke_v2.7` (FNL 체계). `realtime_forecasting` 제외.

## 1. 핵심 구성

| 항목 | 기존 체계 |
|---|---|
| 배출량 처리 | SMOKE 2.7 |
| CMAQ 화학기작 | CB05 + AE5 |
| 격자 | Lambert Conformal; 27 → 9 → 3 → 1 km |
| 국내 인벤토리 | CAPSS 2017; 면·이동 통합, 해상, 점 |
| 국외 인벤토리 | 아시아 및 북한 IDA |
| 시간배분 | SCC별 월/요일/일변화; 시간대 및 공휴일 파일 |
| 화학종 분배 | SCC별 변환계수·프로파일 참조·SPECIATE |
| 공간배분 | 국내 시군구×SCC; 국외 국가×부문×오염물질 surrogate |
| 생물성 | BEIS 3.12 (1 km 산출 흔적 확인) |
| 병합 | Mrggrid의 AREA + POINT + BIO |

```text
IDA 인벤토리(국내 면·이동/해상, 국내 점, 아시아, 북한)
  └─ Smkinven: 7종 읽기, PMC = PM10 - PM2.5 산정
       ├─ 종분배: VOC→TOG/NONHAPTOG, SPECIATE→CB05/AE5
       ├─ 시간배분: SCC별 월·요일·일변화, 공휴일
       ├─ 공간배분: surrogate
       ├─ 점오염원 굴뚝 특성 보정 및 상승 처리
       └─ BEIS 생물성
            → Mrggrid: AREA + POINT + BIO
            → CMAQ 배출파일
```

`filelist.mrggrid.txt`에 AREA·POINT·BIO만 기재되어 있어 국외 배출은 AREA에 사전 합쳐진 것으로 **추정**한다.

## 2. 기존 영역

모두 Lambert Conformal(표준위도 30°/60°, 중심 126°E/38°N).

|---|---:|---|---|
| 27KM | 174×128 | -2,349,000 / -1,728,000 | 국내 250개 시군구, 국외 포함 |
| 09KM | 67×82 | -180,000 / -585,000 | 국내 250개 시군구, 북한 대부분 |
| 03KM | 83×83 | 105,000 / -408,000 | 영남권 국내 중심, 국외 미사용 |

신규 MCIP 격자와 동일하므로 **격자 정의가 실제 일치하는 경우 기존 surrogate 재사용이 가능**하다. 단, 영역별 공간배분 범위와 자료 존재 여부를 별도 QA한다.

## 3. 인벤토리 및 물질

IDA 파일에서 입력되는 7종: **SO2, NOX, CO, PM10, VOC, NH3, PM2.5**.

| 해상 | `area/1_Area_Inventory_File_sea.txt` | 7 | 7 |
| 국내 점 | `point/1_Point_Inventory_File.txt` | 7,882 | 252 |
| 아시아 | `asia/1_New_Asia_Area_Inventory_File.txt` | 553 | 147 |

국내 면 파일에 도로이동(SCC 07)과 비도로이동(SCC 08)이 포함되어 있으며, 과거 이동원 별도 파일은 마지막 구성에 사용되지 않았다.

국내 면+해상 NOX 합계 985,457 ton/yr는 `area_dat/*.ncf` Smkinven 산출 합계와 일치했다.

### IDA 형식 유의사항

- **면:** 6줄 헤더 뒤 한 줄은 지역×SCC. 지역 코드 5자, SCC 10자, 이후 오염물질별 47자 묶음. 실제 값은 각 물질의 연간 배출량이며 나머지 항목은 0.
- **점:** 한 줄은 배출구×SCC, 총 574자. 위치는 위도(231~239)/경도(240~248); 굴뚝 높이(120~123, ft), 지름(124~129, ft), 온도(130~133, °F), 유량(134~143, ft³/s), 속도(144~152, ft/s). 7개 물질은 250자 이후 각 52자 묶음.
- **오염물질 배열 주의:** 구버전 점 인벤토리 순서는 `NOX SO2 CO PM10 VOC PM2_5 NH3`, 2020년 구성은 `SO2 NOX CO PM10 VOC NH3 PM2_5`.
- **코드:** 국내 시군구 11100~11351, 부산 11125~11140, 해상 11352. 국외 인벤토리에는 중국 11001, 북한 11002, 일본 11003, 몽골 11004, 대만 11006, 기타 11007.
- 신규 SMOKE 5.3용 FF10 전환에서는 **고정폭, 단위 및 물질 순서를 필드 단위로 검증**한다.

## 4. 시간배분

- `9_Area_TimeZone.txt`, `9_Asia_TimeZone.txt`, `9_Bio_TimeZone.txt`: 지역·시간대 코드.
- `7_Area_Temporal_Profile.txt`: 월/요일/일변화 프로파일.
- `4_*_Temporal_Reference_Profile.txt`: SCC별 프로파일 매핑.
- `holidays_korea/north/asia.txt`: 국가별 공휴일.

기존은 `TZONES=0(GMT)`로 기록하면서 **일변화 프로파일 값을 UTC로 이동**시켰다. 신규에서는 (a) KST 프로파일+UTC+9 코드표 또는 (b) UTC 프로파일+시간대 0 중 **하나만** 채택한다. 혼용 시 9시간 오류가 난다.

**기존 문제:** 공휴일 파일에서 2021~2030년 월이 모두 `01`로 기재된 오류를 발견했다. 신규 시스템 공휴일 자료를 재작성·검증해야 한다.

## 5. 화학종 분배

- `6_*_Speciation_Conversion_Factor.txt`: SCC별 VOC→NONHAPTOG 변환계수.
- `5_*_Speciation_Reference_Profile.txt`: SCC→VOC/PM2.5 프로파일.
- `gspro_cmaq_cb05_ae5.txt`: CB05/AE5 출력종의 분율·분자량·질량분율.
- 기존 NOX 기본 분할: NO 90%, NO2 9.2%, HONO 0.8%.

**추가 QA:** 일부 VOC 변환계수 0, 161.24, 10.03은 이상 또는 확인 필요. 국외 프로파일 참조의 `TOG`와 변환계수의 `NONHAPTOG` 이름 불일치로 기본 프로파일 적용 가능성이 있으나 **실행 로그 미확인**. 신규 CB6 매핑 작성 시 별도 검증한다.

## 6. 공간배분

- 국내: `2_Surrogate_Description_<영역>_2017_2020update.txt.div`, `2017_CAPSS_<영역>_2020/` (612개 + 기본 999).
- 국외: `2_ASIA_Surrogate_Description_<영역>_meicreas.txt.div.div`, `2010_ASIA_<영역>_2016/` (147개 + 기본 999).
- 연결: 지역/SCC → gridding reference → surrogate 번호 → 영역별 surrogate 조각 파일.
- 국내 surrogate는 **시군구×SCC**, 국외는 **국가×21부문×7물질** 기준. 영역 밖 비율은 제외되므로 잘린 시군구 합계가 1보다 작을 수 있다.
- 국외 03KM 폴더는 부산이 아닌 수도권 65×65 영역이므로 부산 03KM에 재사용하지 않는다.
- **해상:** 27/9km 설명 파일의 해상 surrogate 대상 파일이 운영 자료에서 발견되지 않았다. 인벤토리 포함은 확인했지만 **격자배분 성공 여부는 Grdmat 로그 확인 필요**. 신규 항로 기반 공간배분을 검토한다.

## 7. 점오염원과 생물성

### 점오염원

`pstk.jin.txt` 기본값은 높이 10 m, 지름 0.5 m, 온도 300 K, 속도 5 m/s(값이 0 이하일 때). `pnts.ncf`에서 높이·지름·속도 보정은 확인됐지만 **32°F(0°C) 온도 2,030건은 정상값으로 읽혀 남아 있음**. 배출 유량 원자료는 전부 0. `pelvconfig.top50.txt`에 따른 모든 점오염원 상승처리는 **추정**.

신규 CMAQ inline plume-rise 사용을 계획하되, FF10 변환 단계에서 굴뚝 물리량 및 결측 온도를 먼저 보정한다.

### 생물성

기존 `WRF_LandUse*` BELD3, `b3grd_BIO_nctox.ncf`(BEIS 3.12, 1km, 77개 변수), BEIS 계수 및 CB05 매핑 파일 확인. 다른 기록의 MEGAN v2.04 사용 영역과의 관계는 **실행 스크립트 확인 필요**. 신규 체계는 BEIS4(BELD5) 또는 MEGAN 3.x 입력을 별도 구축한다.

## 8. 신규 SMOKE 5.3 전환 체크리스트

| 우선순위 | 작업 | 기존 자료 활용 | 검증 |
|---|---|---|---|
| 1 | IDA→FF10 면·점 변환 | 원본 인벤토리 | 레코드 수·물질별 ton/yr 합계·좌표/단위 |
| 2 | 지역·시간대 코드 | 기존 코드 구조 | UTC/KST 기준 통일 |
| 3 | 시간 프로파일·공휴일 | 기존 SCC 매핑·분포 | 2021년 이후 공휴일 재작성 |
| 4 | CB6 종분배 | 기존 SCC 매핑 참고 | VOC 계수 이상값·TOG 명칭·mass balance |
| 5 | surrogate 설명·매핑 | 동일 영역의 기존 자료 | 도메인·격자·비율합계, 해상 파일 실재 |
| 6 | 점오염원 굴뚝 QA | 굴뚝 원자료 및 기본값 참고 | 32°F 결측·유량 0·inline 설정 |
| 7 | 국외 배출 중복 제거 | 국가 코드 및 자료 구분 | **아시아 파일과 북한 별도 파일의 중복 방지** |
| 8 | 생물성 신규 산정 | 기존 토지이용 자료 참고 | BEIS4/MEGAN 선택 및 CMAQ 매핑 |
| 9 | 실행·병합 QA | 기존 총량 비교 | 로그, 시간·격자·화학종·부문별 총량 |

**원자료에서 발견한 핵심 중복:** 아시아 파일과 북한 파일 모두에 북한 배출이 존재(원자료 예시 SO2 325,823 및 149,532 ton/yr). 중복 여부와 포함 범위를 재검토해 하나의 북한 배출만 반영한다.

## 9. 검증 범위 및 문서 관계

- **확인됨:** 입력·중간 파일 구조, 코드·프로파일 참조, 일부 단계의 레코드 수 및 총량, 기존 문서에 명시된 격자·자료 버전.
- **추정·미확인:** 실제 최종 병합의 국외 처리 순서, 전체 점오염원 상승 설정, 해상 Grdmat 공간배분, 국외 VOC 기본 프로파일 대체 여부, MEGAN/BEIS 영역별 실행 관계.
- **아직 미수행:** 기존 SMOKE 2.7 재실행/로그 확인, 신규 5.3 부산 사례 실험, CMAQ 입출력 일치 검증.
