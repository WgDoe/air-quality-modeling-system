# MEGAN 문서 읽는 순서 (2026-11-16 갱신)

> **재작업 시작점:** 생물성(식생) 배출량은 SMOKE에서 처리하지 않고 **CMAQ 5.5 CCTM 인라인 MEGAN 3.2**로 계산한다(결정 근거: [SMOKE 03 §9](../smoke/03_SMOKE_Emission_Improvement_Plan.md#busan-inline-megan)). 이 장은 CCTM이 읽는 시간 불변 입력 3종(`MEGAN_CTS`, `MEGAN_EFS`, `MEGAN_LDF`)을 도메인별로 만드는 전처리만 다룬다. SMOKE 실행과는 서로 영향을 주지 않으며, 두 결과는 CCTM에서 처음 만난다.

| 순서 | 문서 | 읽는 목적 |
|---|---|---|
| **01 필수** | [MEGAN 3.2 입력 전처리 가이드](01_MEGAN32_Input_Preprocessing_Guide.md) | 전처리기 설치·수정·컴파일, 공용 원자료 준비, 4개 도메인 입력 생성·검증 |

## 현재 작업 재개 위치

- **완료 확인(2026-11-16):** 27·09·03·01KM의 CT3·EFMAP·LDF 생성 기록이 있다. 기존 LDF 열 매핑 오류를 수정한 뒤, 네 도메인의 `LDF03`~`LDF06`이 EFP CSV와 일치하고 값이 0~1 범위인 것을 사용자 제공 로그로 확인했다. 도메인별 운영 LDF는 사례 파일과 MD5·`cmp` 비교에서 모두 동일했다([01 §7.2.1](01_MEGAN32_Input_Preprocessing_Guide.md)).
- **다음:** LDF 전처리·운영본 일치 확인은 완료됐다. 남은 작업은 CCTM 인라인 MEGAN 3.2에 CT3·EFMAP·LDF 연결, 실행 로그 확인, 이소프렌·모노테르펜·토양 NO 진단([01 §8](01_MEGAN32_Input_Preprocessing_Guide.md)). **CCTM 실행은 아직 미실행**이다.
- **다시 만들 필요:** 격자(GRIDDESC의 투영·원점·간격·행열)가 같으면 기간·사례·화학 메커니즘이 바뀌어도 그대로 쓴다. 격자, 원자료(배출계수표·종 구성표·식생 지도), 결측 처리 기준이 바뀔 때만 다시 만든다.
- **설치·생성 파일:** [files/](files/)에 설치 스크립트·도메인 실행 스크립트·파이썬 4개·패치 1개가 있다. 대용량 원자료는 저장소에 없으며 설치 스크립트가 내려받는다.

> 번호는 **읽는 순서**를 의미하며 모델 실행의 Phase 번호와는 별개입니다. `files/`는 설치용 파일이므로 문서 순서에 포함하지 않습니다.
